---
title: Quickstart
description: Run the offline example with Python 3.11 or newer
---

```bash
git clone https://github.com/Idopt-Lab/transitPricePredictionModels.git
cd transitPricePredictionModels
pip install -e '.[test]'
python example.py --origin ROA --destination CLT
```

Use `main`. The repository is private and requires lab access.

```python
from air_travel_model import TransportPredictor

predictor = TransportPredictor()
result = predictor.quote('air', 'ROA', 'CLT', max_connections=0)
print(result['status'], result['price_usd'], result['time_minutes'])
```

Read the [API reference](/air-travel-model/api/quotes) for the full contract,
or its source `docs.md` in the repository root. Missing is not zero.
Use `allow_heuristic=True` only when an explicitly labeled approximate formula
is acceptable. Train station data and fare coverage remain incomplete.
