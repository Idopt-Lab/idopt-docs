---
title: Offline versus legacy routing
description: Know which entry points can make network calls
---

`TransportPredictor.quote` and `quote_many` are offline. Drive time uses the
existing offline speed model, while distance is great-circle times 1.15.
This is an estimate, not a routing service or proof of road connectivity.

Legacy `predict('drive_time', ...)`, `estimate('drive_time', ...)` and
`predict('drive_fare', ...)` can contact OSRM. Legacy `plan_trip` can use external
routing depending on its provider configuration. Do not use those entry points
when an offline contract is required. OSRM is a network service, not offline mode.

Previous point comparisons against the same routing API are not independent
holdout evidence. No general accuracy percentage is claimed on this page.
