The repository is now `transitPricePredictionModels`; Python imports remain
`air_travel_model`. Use `TransportPredictor.quote()` and `quote_many()` for the
consistent price/time result contract. The canonical reference is `docs.md` at
the repository root; `scripts/build_mintlify.py` builds its publishing directory.

Commercial air reuses existing observed averages and trained predictors. RAM
uses an operating-cost formula. Driving uses an offline time model with a
distance-based vehicle cost. Bus/train are not claimed trained or complete:
missing artifacts are explicit, heuristics require opt-in, and train fare is absent.

Interface tests are not price-accuracy evidence. Historical average fares are
not live ticket quotes. No new mode was trained merely by adding the unified API.
